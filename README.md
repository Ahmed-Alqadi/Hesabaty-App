## 📖 نبذة عن التطبيق (About Hesabaty)

**«حساباتي» (My Accounts)** هو تطبيق أندرويد احترافي شامل، صُمم خصيصاً لمساعدة الأفراد وأصحاب المتاجر والمشاريع الصغيرة على تنظيم حساباتهم المالية بدقة ومرونة متناهية. يُمكّنك التطبيق من مراقبة كافة المعاملات المالية (ما لك وما عليك)، وجدولة الدفعات والأقساط، وتتبع حركات الأموال لحظة بلحظة بدون أي تعقيد محاسبي، مع العمل الكامل **بدون إنترنت (Offline-First)** وتوفير خيارات مزامنة ونسخ احتياطي سحابي فائقة الأمان.

## ✨ أبرز المميزات والإمكانيات

### 1. 👥 إدارة الحسابات والأشخاص بكل سلاسة
* **تسجيل جهات التعامل:** تصنيف الأشخاص (عميل، مورد، صديق، عائلة، عمل، جار، أخرى).
* **معاملات دقيقة ثنائية الاتجاه:**
  * 🟢 **أعطيته (لي عنده):** لتسجيل المبالغ التي دفعتها أو سلفتها.
  * 🔵 **أعطاني (عليّ له):** لتسجيل السدادات والدفعات المستلمة.
* **رصيد فوري ولحظي:** معرفة الرصيد الصافي لكل شخص وحالته (*لي عنده / عليّ له / الحساب متعادل*).
* **إرفاق الصور والمستندات:** إمكانية التقاط صورة للفاتورة أو الإيصال أو المستند الورقي وإرفاقه مع كل حركة مالية.

### 2. 📅 إدارة الأقساط والجدولة الذكية (Installments)
* إنشاء خطط سداد للأقساط وتحديد المبالغ وتواريخ الاستحقاق الدورية.
* متابعة الأقساط المدفوعة والمتبقية والمتأخرة بنسب مئوية واضحة.
* تنبيهات ذكية تفاعلية لتذكيرك بمواعيد السداد قبل حلولها.

### 3. 📄 طباعة كشوف الحساب وسندات القبض/الصرف (PDF)
* **كشوف حساب رسمية احترافية:** إصدار كشف حساب تفصيلي خلال أي فترة زمنية جاهز للطباعة أو المشاركة بتنسيق PDF عالي الجودة.
* **سندات القبض والصرف:** إنشاء سند رسمي لكل عملية دفع أو قبض يحتوي على QR Code ومعلومات العملية.
* **التفقيط المالي باللغة العربية:** تحويل الأرقام تلقائياً إلى صيغة نصية عربية فصحى معتمدة (*مثال: فقط مائتان وخمسون ألف ريال لا غير*).
* **تصدير Excel / CSV:** تصدير كافة العمليات بضغطة زر لفتحها وتحليلها في برامج الجداول الحسابية.

### 4. 💬 الإرسال والمطالبة عبر واتساب وتليجرام (Smart Messaging)
* إرسال إشعار فوري للشخص بمجرد تسجيل حركة مالية جديدة.
* إرسال ملخص كشف الحساب ورسائل التذكير اللطيفة عبر **واتساب** أو **تليجرام** بضغطة زر دون الحاجة لكتابة رسائل يدوية.
* إرسال دوري ومجدول لكشوف الحسابات (أسبوعي، كل 10 أيام، كل أسبوعين، أو شهري).

### 5. 📊 رسوم بيانية وتحليلات مالية متقدمة (Analytics)
* **شاشات التحليل المالي:** رسوم بيانية توضح التدفقات النقدية الشهرية الواردة والصادرة.
* **مخطط الفئات (Pie Charts):** استعراض توزيع الأموال والديون حسب التصنيفات.
* **إحصائيات إجمالية في الشاشة الرئيسية:** إجمالي ما لك في السوق، وإجمالي ما عليك للآخرين، وصافي المركز المالي.

### 6. 🔒 أمان وخصوصية فائقة (Biometrics & PIN)
* **قفل التطبيق برمز حماية (PIN Code):** حماية بياناتك وأرقامك المالية من أعين المتطفلين.
* **دعم البصمة والقياسات الحيوية (Biometric Authentication):** فتح التطبيق بسرعة وسهولة عبر بصمة الإصبع أو الوجه.
* **سجل تدقيق كامل للعمليات (Audit Log):** تتبع جميع عمليات الإضافة والتعديل والحذف لمنع أي تلاعب.
* **سلة المحذوفات (Recycle Bin):** استعادة أي شخص أو عملية حُذفت عن طريق الخطأ.

### 7. ☁️ النسخ الاحتياطي والمزامنة السحابية (Cloud & Offline)
* **قاعدة بيانات محلية فائقة السرعة (Hive NoSQL):** يعمل التطبيق بالكامل بدون إنترنت، استجابة فورية بدون أي تأخير.
* **النسخ الاحتياطي السحابي عبر Google Drive:** حفظ واسترجاع بياناتك على حسابك الشخصي في جوجل درايف بضغطة واحدة.
* **مزامنة Supabase Cloud:** خيار المزامنة السحابية الفورية.
* **تصدير واستيراد النسخ الاحتياطية محلياً:** إمكانية حفظ نسخة احتياطية مشفرة ونقلها إلى أي هاتف آخر.

### 8. 🎨 تجربة مستخدم عصرية وأنيقة
* دعم كامل للغة العربية واتجاه اليمين لليسار (RTL).
* مظهر ليلي داكن فاخر (Dark Mode) ومظهر نهاري مريح للعين (Light Mode).
* فلترة وبحث ذكي وفوري بالاسم، المبلغ، التاريخ، أو الملاحظات.

## 🛠️ المواصفات التقنية (Tech Stack)

* **لغة البرمجة وإطار العمل:** Flutter 3.x / Dart (أداء عالي متعدد المنصات).
* **قاعدة البيانات:** Hive NoSQL Database (محفظة مشفرة ومخزنة محلياً بسرعة خيالية).
* **المزامنة السحابية:** Google Drive API v3 & Supabase Flutter Client.
* **محرك التقارير:** PDF Engine & Printing مع خطوط عربية مدمجة (Tahoma & Arial) لدعم التشكيل والتفقيط الصحيح.
* **الحماية:** Local Authentication (Biometrics / Fingerprint / PIN Code).

## 🌐 English Overview

**Hesabaty (My Accounts)** is a comprehensive, offline-first personal & commercial debt manager and ledger ledger mobile app for Android.

### Key Highlights:
- **Offline-First & Ultra-Fast:** Built with Flutter and Hive NoSQL, operates without any network connection.
- **Debts Tracking:** Precise two-way transaction bookkeeping ("I gave / Receivable" and "I received / Payable").
- **PDF Reports & Receipts:** Generate official accounting statements, receipt vouchers, Arabic text spellout of numbers (Tafqeet), and CSV/Excel exports.
- **Smart Messaging:** Automated messaging and statements via WhatsApp and Telegram with customizable templates.
- **Security & Privacy:** Biometric fingerprint unlock, PIN passcode security, audit trails, and recycle bin for safe recovery.
- **Backup & Cloud Sync:** Automated Google Drive backups and optional Supabase cloud synchronization.
